📁 Sub-topic 5: Product-Level Analysis

This folder contains all SQL scripts and output datasets for evaluating product sales performance, new product launch impact, cross-selling funnels, product portfolio expansion, and refund rate analytics for Fuzzy Factory.

---

📊 Core Modules & SQL Scripts

| # | Module Link | SQL Script(s) | Data Output(s) | Description |
| :-: | :--- | :--- | :-: | :--- |
| **1** | [Product Sales Analysis](./01_product_sales_analysis) | `product_sales_analysis.sql` | `CSV` | Track monthly sales volume, total revenue, margin contribution, and growth trends across individual product offerings. |
| **2** | [Product Launch Analysis](./02_product_launch_analysis) | `product_launch_analysis.sql` | `CSV` | Measure the performance impact, conversion lift, and traffic pull following new product launches. |
| **3** | [Product-Level Website Pathing](./03_product_level_website_pathing) | `product_level_website_pathing.sql` | `CSV` | Analyze user navigation flow from product landing pages to cart and checkout to optimize product conversion funnels. |
| **4** | [Cross-Sell & Portfolio Analysis](./04_cross_sell_portfolio_analysis) | `cross_sell_portfolio_analysis.sql` | `CSV` | Evaluate cross-sell conversion rates, multi-product order basket sizes, and average order value (AOV) impact. |
| **5** | [Product Refund Analysis](./06_product_refund_analysis) | `product_refund_analysis.sql` | `CSV` | Monitor product refund rates, return trends, and quality issues across different product lines over time. |
